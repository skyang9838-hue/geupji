# 급지.gg

수도권 대장아파트 티어. 국토교통부 실거래가로 매일 새로 매기는 "아파트판 op.gg".

- 지역마다 대장 단지 하나, 전용 84㎡ 최근 90일 실거래 중위값(대표가)으로 줄을 세운다
- 티어는 리그 오브 레전드 랭크를 따른다: 챌린저(1자리) · 그랜드마스터(2자리) · 마스터 30억 · 다이아몬드 25억 · 에메랄드 20억 · 플래티넘 16억 · 골드 12억 · 실버 9억 · 브론즈 6억 · 아이언. 아이언~다이아는 IV~I 디비전과 LP
- 해제된 거래와 직거래는 가격 계산에서 뺀다

## 개발

```bash
npm install
npm run db:dev                     # 로컬 Postgres (다른 터미널)
npx prisma migrate deploy
npx tsx scripts/seed-sample.ts     # 가상 시장으로 채우기 (견본 데이터)
npm run dev
```

실데이터: `.env.local`에 공공데이터포털 인증키(`MOLIT_SERVICE_KEY`)를 넣고 `npm run ingest -- --from 202101`.

자료 출처: 국토교통부 「아파트 매매 실거래가 상세 자료」(공공데이터포털). 이 서비스는 투자를 권하지 않습니다. 티어 이름은 리그 오브 레전드에서 빌렸고 Riot Games와는 관계없습니다. 엠블럼은 새로 그렸습니다.
